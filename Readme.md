This project is to show how to use worktree in claude code.

we first talk about the worktree, and then we will show how to use it in claude code.

Worktree is a feature of git that allows you to have multiple working directories for a single git repository. This is useful when you want to work on multiple branches at the same time, or when you want to have a separate working directory for testing or experimentation.

To create a worktree with claude code command, you can use the following command:

```bash
claude --worktree <worktree-name>
```
